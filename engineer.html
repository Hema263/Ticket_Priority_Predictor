HIGH PRIORITY - Urgent Problems

System detects critical issues that prevent functionality:

System Status Issues: not working, not accessible, cannot access, unable to, down, offline, unavailable, broken, crash, error, failed, stopped, outage, disconnected, no connection
Service Downtime: server down, network down, system down, service down, website down, application down, database down, production down
Critical Language: urgent, critical, emergency, immediate, asap, blocking, severe, major, serious
Security Issues: security breach, hacked, compromised, data loss, data breach, unauthorized access, malware, virus, attack
Working Issue Patterns: cannot, unable, not able, doesn't work, won't work, not responding, not loading, not opening, not starting

MEDIUM PRIORITY - Performance Issues

System detects performance degradation or speed issues:

Speed/Performance Indicators: slow, slower, slowing, lag, lagging, delayed, delay, degraded, degradation, poor performance, performance issue
Time-related Issues: taking time, timeout, time out, hanging, freezing, intermittent, sometimes, occasionally, unstable
Optimization Requests: optimization, optimize, improve performance, speed up, bottleneck, congestion

LOW PRIORITY - Information Requests

System detects questions, inquiries, or non-urgent requests:

Question Indicators: question, questions, ask, asking, inquiry, inquiries, information, info, want to know, wondering, curious
Question Patterns: how to, how do, what is, what are, explain, explanation, clarification, clarify, understand, understanding
General Requests: general, general question, just asking, for information, feature request, suggestion, idea, enhancement
Non-Urgent Language: non-urgent, when possible, whenever, nice to have, cosmetic, minor, small, low priority
Question Word Detection: If 2+ question words (?, why, what, how, when, where, which, who) detected → Low Priority
Classification Algorithm: The system analyzes the entire problem description (title + description) using pattern matching and context analysis. Priority is assigned based on problem nature, not just keywords. If no clear indicators match, the ticket defaults to Medium Priority.
